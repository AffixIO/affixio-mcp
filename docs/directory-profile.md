# AffixIO Verification MCP

**Short description:** Proof verification, permission checks, attestations and Merkle audit evidence through OAuth.

**Endpoint:** https://www.affix-io.com/mcp/

**Website:** https://www.affix-io.com/mcp/

**Repository:** https://github.com/AffixIO/affixio-mcp

**Hosted install guide:** https://github.com/AffixIO/affixio-mcp/blob/master/docs/hosted-mcp.md

**Official registry name:** `com.affix-io/affixio`

**Contact:** kris@affix-io.com

**Logo:** https://www.affix-io.com/logo.png

**Categories:** Developer tools, security, verification, audit evidence, agent permissions.

AffixIO's hosted MCP server connects authorised clients to proof verification, proof-based permission checks, spent/revocation status, attestations and Merkle inclusion evidence. Focused tools and an OpenAPI resource help clients use concrete contracts. OAuth scopes distinguish reads from writes; successful proof verification can consume a proof. Applications remain responsible for enforcing decisions.

An AffixIO account and active account-owned API key are required for hosted access. Usage follows account pricing and limits. Free directory submission does not mean unlimited free API usage. The repository also contains a separate local stdio package; its tools and privacy model differ from the hosted service.
